# Cyberpunk 2077 Randomizer

# Usage
> [!WARNING]
> You need to use Bash (and Git or Curl) to run the script.

```
git clone https://github.com/ch1ebak/cyberpunk2077-randomizer; cd cyberpunk2077-randomizer; ./cyberpunk2077-randomizer
```

OR

```
bash <(curl -s https://raw.githubusercontent.com/ch1ebak/cyberpunk2077-randomizer/refs/heads/main/cyberpunk2077-randomizer)
```

## What does this do?
This script randomizes available lifepaths, endings, apartments, vehicles, operating systems, and weapons. Additionally, it provides a random debuff to make the game more interesting.

The script can be used for vanilla and modded playthroughs.

## Rules
- Weapon, Vehicle, and OS should be ignored if affected by a Debuff (I'll fix this eventually).
- Fists and Grenades are allowed until a Weapon is obtained, unless affected by a Debuff.
- Only use the rolled Weapon, Vehicle, or OS unless forced by the game.
- Everything should be obtained legitimately.

## Debuffs.

The following debuffs are available:
- Body must be upgraded, but only to level 14
- Body needs to be upgraded to level 15 before any other skills can be upgraded
- Can only spend attribute/perk points at levels 20/40/(50)60
- Can only upgrade/install new cyberware at levels 20/40/(50)60
- Cool must be upgraded, but only to level 14
- Cool needs to be upgraded to level 15 before any other skills can be upgraded
- Inteligence must be upgraded, but only to level 14
- Inteligence needs to be upgraded to level 15 before any other skills can be upgraded
- Metro Only: cannot use fast travel or vehicles. Walking, running, dashing/air dashing is permitted.
- No Car Stealing: it might take some time for you to obtain the rolled vehicle, so you might be tempted to steal cars. Rolling this option prohibits that.
- No Cyberware: can't use any cyberware, unless forced by the game (pretty much only the Face cyberware). Cyberware installed by Viktor should be removed.
- No Spending Points: cannot spend Attribute, Perk, and Relic points.
- No Stealth: stealth is prohibited for all enemy encounters.
- No Weapon: weapons cannot be used unless forced by the game (cut scenes, etc.). Fists, Grenades, and Cyberdecks (if rolled) are permitted.
- Reflexes must be upgraded, but only to level 14
- Reflexes needs to be upgraded to level 15 before any other skills can be upgraded
- Stealth Only: only stealth is allowed. For extra difficulty, reload the mission/gig if detected (optional).
- Technical Ability must be upgraded, but only to level 14
- Technical Ability needs to be upgraded to level 15 before any other skills can be upgraded
- Used Cyberware Capacity cannot exceed half of the available capacity

## Mods
Selecting "Modded" adds the following options:
- [Always Wanted](https://www.nexusmods.com/cyberpunk2077/mods/18168)
- [Combat Evolved](https://www.nexusmods.com/cyberpunk2077/mods/29125), [Street Sense](https://www.nexusmods.com/cyberpunk2077/mods/28989), and [Night City Remembers](https://www.nexusmods.com/cyberpunk2077/mods/29008)
- [Dark Future](https://www.nexusmods.com/cyberpunk2077/mods/16300)
- [EconomyPunk](https://www.nexusmods.com/cyberpunk2077/mods/16952)
- [Enemies of Night City](https://www.nexusmods.com/cyberpunk2077/mods/8467)
- [Enemy Multiplier](https://www.nexusmods.com/cyberpunk2077/mods/27637)
- [HARDCORE22V2](https://www.nexusmods.com/cyberpunk2077/mods/12569)
- [Shattered Chrome](https://www.nexusmods.com/cyberpunk2077/mods/29105), [Chrome Plating](https://www.nexusmods.com/cyberpunk2077/mods/29101), and [Flesh And Chrome](https://www.nexusmods.com/cyberpunk2077/mods/28375)
- [Vehicle](https://www.nexusmods.com/cyberpunk2077/mods/10039), [Life](https://www.nexusmods.com/cyberpunk2077/mods/10569), and [Cyberware](https://www.nexusmods.com/cyberpunk2077/mods/24952) Insurance
- Weapon Randomizer: [Weapon Shuffle (Randomizer)](https://www.nexusmods.com/cyberpunk2077/mods/15200) / [Random Weapon on Kill](https://www.nexusmods.com/cyberpunk2077/mods/16763) / [Weapon Randomizer](https://www.nexusmods.com/cyberpunk2077/mods/15255)

Both Vanilla and Modded have "Homeless" as a debuff that can be rolled as Apartment. This prohibits using apartments (player or NPC) unless forced by the game (for example, the prologue cut scene). For modded playthroughs, you can use [Rent a Motel](https://www.nexusmods.com/cyberpunk2077/mods/21729); I also recommend installing [Eviction Notice](https://www.nexusmods.com/cyberpunk2077/mods/23187). If you have Dark Future installed, sleeping in cars is permitted.
